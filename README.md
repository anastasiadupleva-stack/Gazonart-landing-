# GazonArt — Landing Page

Pagină de prezentare pentru **GazonArt**, servicii de gazon rulou, gazon prin
însămânțare și irigare automatizată în Republica Moldova.

## Structură

- `index.html` — conținutul și structura paginii
- `style.css` — stiluri (paletă verde modernă, layout responsive)
- `script.js` — meniu mobil + anul curent în footer

## Cum o deschizi local

Descarcă/clonează folderul și deschide `index.html` direct într-un browser —
nu necesită server sau build step.
